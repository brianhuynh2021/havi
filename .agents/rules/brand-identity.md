# Havi Brand Identity, Origin & Print Rules

- **Brand Soul**: **Havi** = **Harry** (con trai yêu quý của Founder — đại diện tương lai, tình cảm gia đình và sự bảo bọc) + **Vietnam** (khát vọng trí tuệ Việt, nâng tầm doanh nghiệp Việt).
- **Core Visual Metaphor**: Dynamic italicized letter "H" fused with an ascending velocity growth arrow, glowing cyan AI core node, and dark squircle background.
- **Palette**:
  - Electric Indigo: `#4F46E5` | CMYK (75, 75, 0, 0)
  - Ultra Violet: `#7C3AED` | CMYK (65, 80, 0, 0)
  - Cyan Pulse: `#00D2FF` | CMYK (60, 0, 0, 0)
  - Deep Space Navy: `#090D16` | CMYK (85, 75, 55, 75)
